# Lucky Number
## Number Guessing Game

This project is a Python number guessing game.

The computer selects a random number between 1 and 100.
The player has 5 attempts to guess the correct number.

### Features
- Random number generation
- Limited attempts
- Remaining attempts counter
- Smart hints based on distance
- Player ranking
- Displaying the secret number after losing
- Replay option
- Input validation

### Technologies
- Python
- Random module
- Functions
- While loops
- Conditional statements
- Dictionary
- Try and Except

### How to Run
Run the following file:

guess_number_game.py
